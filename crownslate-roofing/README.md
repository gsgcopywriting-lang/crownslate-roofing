# Demo site — deploy to Vercel via GitHub

1. Create a new GitHub repo and push these files to it (index.html, style.css, and script.js if present go in the repo root).
2. Go to vercel.com → "Add New Project" → import that GitHub repo.
3. Framework preset: choose "Other" / static site. No build command needed — leave Build Command and Output Directory blank.
4. Click Deploy. Vercel will give you a live URL in under a minute.
5. Optional: add a custom domain later under Project Settings → Domains.

This is a static site with no dependencies, so there's nothing else to configure.
